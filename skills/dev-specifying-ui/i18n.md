# Language, locale and direction (G5)

Read this when the product ships in more than one language, or may. "May" is most products: retrofitting
i18n costs a rewrite of every string, while doing it from the first screen costs a key per string.
`DEV-PROFILE §Project` says the locales; with only one, still externalise strings, and skip the rest.

## Strings

- Every user-visible string is a key in a message catalogue, never a literal in a component. That
  includes error messages, empty states, page titles, `aria-label`s and email templates.
- A message is a whole sentence with placeholders, never fragments joined in code: `"{count} files
  deleted by {name}"`, not `count + " files deleted by " + name`. Word order differs by language.
- Plurals use the plural rules of ICU MessageFormat or the platform's equivalent:
  `{count, plural, one {# file} other {# files}}`. English has two forms; Arabic has six; Vietnamese and
  Japanese have one. `count === 1 ? … : …` is wrong in most languages.
- Gender and other selections use `select`, never string concatenation.
- The key names the meaning (`invoice.list.empty`), not the English text, so fixing a typo in English
  does not orphan every translation.

## Formats come from the locale, never from code

Dates, times, numbers, currencies, units, lists ("A, B and C") and relative times ("3 days ago")
go through `Intl` (or the platform's locale API) with the user's locale and time zone. Store time in
UTC; render in the user's zone. Store money as an integer amount plus an ISO currency code, never as a
float.

## Layout survives other languages

- German and Finnish strings run about 30 % longer than English; some labels double. Buttons and table
  headers wrap or truncate with a tooltip, and the spec says which.
- CJK text has no spaces to break on. Vietnamese stacks diacritics above and below the line, so line
  height must not clip them.
- Right-to-left languages (Arabic, Hebrew) mirror the layout. Use logical CSS properties
  (`margin-inline-start`, not `margin-left`), set `dir` on the root, and mirror direction icons
  (arrows, chevrons) but not media controls or logos.

## What the ui-spec states, per screen

The longest string expected in each fixed-width element, at the locale where it is longest. The
behaviour when it does not fit. Any locale-specific content (legal text, address forms, phone
formats). G5 fails a screen whose strings are literals, or whose plurals are hand-built, when the
profile names more than one locale.
