# Lessons — <root>/learnings/

What this project has learned across initiatives, one lesson per `LRN-<TOPIC>.md` (DEV-CONTRACTS §19).
Written by `/sdlc-learn` only, after `node <root>/scripts/learn.mjs check` passes. Read at the start of
every stage through `learn.mjs recall --gate <G> --stage <stage>` (an index: title and probe per hit),
then `learn.mjs show <id> …` for the ones that apply.

A lesson is a habit for next time, cited to the gate logs, post-release reports or human statement it
came from. Facts about the system belong in `knowledge/`; open questions in `decisions/`.
