# problem.md (excerpt) — release approvals, change class initiative

## Success looks like

Outcome (north star): weekly active teams that ship a release through the tool. Inputs: releases created per team, time from submit to approval. Guardrail: support tickets per release must not rise.
Kill: fewer than 5 of the 20 pilot teams approve a release in the tool within 6 weeks.

## Evidence

Competitor Y has release approvals, so our users want them too.

## Smallest test

A feature flag for 3 pilot teams for two weeks; then 25 % of teams; then everyone.
