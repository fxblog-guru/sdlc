# ui-spec.md (excerpt) — releases list

## Navigation

Top navigation: Releases, Trains, Settings (glossary terms). Task "approve a release": Releases → the row's Approve button, two steps from home. Row actions Edit and Delete are always-visible labelled buttons.

## Accessibility

Tab order follows reading order. A dialog moves focus to its first field and returns it to the trigger on close. A failed save moves focus to the error summary. "Saved" and "Upload failed" are announced in a polite live region. Icon buttons have accessible names (Close, Search).
