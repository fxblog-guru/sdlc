## Release

Store rollout 5 % → 20 % → 100 % over ten days. Minimum supported app version 1.6; the API still returns `site_name`, which 1.6 reads. Location is asked when the user first taps "Check in", with the reason. Every screen shows its last data offline, with a banner.
